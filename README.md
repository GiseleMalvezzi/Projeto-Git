## 📋 Sobre
Portfólio de projetos em Python e R focados em ciências da saúde: análise de dados clínicos, bioestatística, epidemiologia e informática em saúde.

## 🐍 Python
- Limpeza e preparação de dados clínicos
- Análise estatística e modelos preditivos
- Visualização de dados (Plotly, Seaborn, Matplotlib)
- Integração com APIs de saúde

## 📊 R
- Análise de ensaios clínicos
- Estudos epidemiológicos
- Relatórios automatizados (RMarkdown)
- Controle de qualidade de dados

## 🛠️ Stack
**Linguagens**: Python, R, SQL  
**Python**: Pandas, NumPy, SciPy, Scikit-learn, Statsmodels  
**R**: tidyverse, data.table, ggplot2, caret, survival  
**Ferramentas**: Jupyter, RStudio, Git
